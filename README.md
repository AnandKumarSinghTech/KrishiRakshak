# 🌱 KrishiRakshak

KrishiRakshak is a full-stack web application that helps farmers detect crop diseases and receive weather-based alerts. Users can upload crop images, enter crop details, and get disease information along with prevention and treatment suggestions.

## 🚀 Features

- User Signup and Login
- Crop Disease Detection
- Upload Crop Images
- Weather Updates Based on User Location
- Farming Alerts
- Disease Prevention and Treatment Suggestions
- Responsive User Interface

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### APIs
- OpenStreetMap API (Location)
- Weather API
- Browser Geolocation API (`navigator.geolocation`)

## 📌 How It Works

1. User signs up or logs in.
2. The dashboard fetches the user's location and displays weather information.
3. The user uploads a crop image and enters crop details.
4. The backend processes the request and matches it with the disease dataset.
5. The application displays the detected disease along with its description, prevention methods, and treatment recommendations.
